# Envelope-preserving surrogate and stronger matched control

Frozen before these scores. V transport has already been inspected and did not
establish superiority. This is a new exploratory hypothesis; no fresh-test claim.

Legacy surrogate changes individual Fourier phases and can alter the envelope
that carries fault periodicity. New envelope surrogate uses one common phase
rotation for all positive non-DC/non-Nyquist Fourier bins of a demeaned waveform.
Equivalently a real part of a globally rotated analytic signal. Before clipping,
analytic-envelope magnitude and Fourier magnitude are preserved (apart from the
unrotated DC/Nyquist terms). This changes time-domain waveform without independently
randomizing sideband phase differences. This mathematical identity is not proof
of a physically possible independent fault specimen or correct fault label.
Sample64 variants per donor using random donor-window selection and global phase
uniformly in[-pi,pi]. No target fault access. Output quantization and8g clipping;
record clipping because it breaks exact mathematical preservation. Do not choose
samples by classifier success. Not an invention of a new signal transform.

Use every previous clean Y selected classifier/representation for the SAME target,
seed and donor budget. Reproduce Y real-only prediction counts before interpreting
augmentation. No refitting classifier selection on any outer test. Comparison:
real, duplicate, legacy surrogate, severity, transport, transport_mix, envelope.
Each gets same classifier, same real donor events, same total penalty weight.
Fixed synthetic mass0.25 PRIMARY; mass0.5 secondary sensitivity. Never select mass
using outer scores. All180 Y tasks, early and severe, all four classes. Compare
to real and duplicate, and report per-bearing bootstrap with previous caveats.
Improvement of one state alongside degradation of the other is not a full success.

Y's selection protocol differs from V inner CV; this study isolates augmentation
around an existing strong baseline. Y/UORED have been reused many times. A positive
result still needs independent-source confirmation. External datasets already
used by V are no longer unseen. No industrial readiness claim from this study.
